# PACE · 나만의 운동 리듬

**사이트: https://neegiman.github.io/work/**

모바일 중심의 운동 인터벌 타이머입니다. 기본 루틴은 **30초 유지 × 3세트, 세트 간 45초 휴식**이며, 마지막 세트 뒤에는 휴식 없이 완료됩니다.

- 운동·휴식 자동 전환 및 세트 진행 표시
- 시작·일시정지·재개·초기화·구간 건너뛰기
- 운동별 시간·휴식·세트·준비 시간을 이 기기의 로컬 스토리지에 자동 저장
- `+` 버튼으로 이름을 붙인 운동 추가
- 화면 켜짐 유지, 알림음, 집중 모드
- 플랭크·팔굽혀펴기 3D 자세 가이드: 드래그 회전, 시점 선택, 팔굽혀펴기 동작 재생

## 맨몸 운동 기본값

| 운동 | 한 세트 | 세트 간 휴식 | 세트 |
| --- | --- | --- | --- |
| 플랭크 | 30초 유지 | 45초 | 3 |
| 팔굽혀펴기 | 30초 운동 | 60초 | 3 |

직접 바꿀 수 있는 타이머 초기값입니다. 처음 접속하면 플랭크를 선택하며, 기존 사용자의 마지막 선택과 개인 설정은 유지합니다. 이미 같은 이름으로 추가한 운동의 설정도 복원합니다.

## 3D 자세 가이드

플랭크 또는 팔굽혀펴기를 선택한 뒤 타이머 위의 **3D 자세** 버튼을 누르세요. 손가락이나 마우스로 회전하고, 측면·정면·사선으로 시점을 바꿀 수 있습니다. 키보드 방향키로도 조절합니다. 팔굽혀펴기는 시작 자세·내려간 자세를 비교하거나 동작을 재생할 수 있습니다. 가이드를 열어도 운동 타이머는 계속 진행합니다.

기본자세를 설명하는 단순화 모델이며, [ACE 플랭크 안내](https://www.acefitness.org/resources/everyone/exercise-library/32/front-plank/)와 [NASM 팔굽혀펴기 안내](https://www.nasm.org/resource-center/exercise-library/push-up)를 참고합니다. 3D를 지원하지 않는 환경에서는 측면 그림과 설명을 표시합니다.

Three.js 0.186.1은 `vendor/three/`에 MIT 라이선스와 함께 포함되어 있습니다. 3D 코드는 가이드를 처음 열 때 불러오며, 닫거나 페이지가 보이지 않으면 렌더링을 멈춥니다.

화면 켜짐 유지는 지원 브라우저에서 준비·운동·휴식·일시정지 중 적용되며, 운동 완료 시 해제됩니다. 시스템 절전 정책이나 직접 화면 잠금은 막을 수 없습니다. 설정은 같은 기기의 같은 브라우저에서 복원되며, 브라우저 데이터를 지우면 삭제됩니다.

## 배포

이 저장소는 빌드가 필요 없는 정적 사이트입니다. GitHub Pages가 `main` 브랜치의 루트(`/`)를 게시합니다. `.nojekyll`은 정적 파일을 그대로 배포하도록 합니다.

`index.html`과 같은 위치에 CSS 및 JavaScript 파일을 유지하세요. 모든 파일 경로는 상대 경로이므로 `/work/`에서 동작합니다.

JavaScript를 수정할 때는 HTML의 앱 진입 파일과 변경된 모듈 import의 `?v=` 버전도 갱신해 이전 캐시 대신 새 파일을 불러오게 합니다.
