# PACE · 나만의 운동 리듬

**사이트: https://neegiman.github.io/work/**

모바일 중심의 운동 인터벌 타이머입니다. 기본 루틴은 **30초 유지 × 3세트, 세트 간 45초 휴식**이며, 마지막 세트 뒤에는 휴식 없이 완료됩니다.

- 운동·휴식 자동 전환 및 세트 진행 표시
- 시작·일시정지·재개·초기화·구간 건너뛰기
- 운동별 시간·휴식·세트·준비 시간을 이 기기의 로컬 스토리지에 자동 저장
- `+` 버튼으로 이름을 붙인 운동 추가
- 화면 켜짐 유지, 알림음, 집중 모드
- 플랭크·팔굽혀펴기 이미지 자세 가이드: 정지 시안 3장과 팔굽혀펴기 두 자세 비교

## 맨몸 운동 기본값

| 운동 | 한 세트 | 세트 간 휴식 | 세트 |
| --- | --- | --- | --- |
| 플랭크 | 30초 유지 | 45초 | 3 |
| 팔굽혀펴기 | 30초 운동 | 60초 | 3 |

직접 바꿀 수 있는 타이머 초기값입니다. 처음 접속하면 플랭크를 선택하며, 기존 사용자의 마지막 선택과 개인 설정은 유지합니다. 이미 같은 이름으로 추가한 운동의 설정도 복원합니다.

## 자세 가이드

플랭크 또는 팔굽혀펴기를 선택한 뒤 타이머 위의 **자세 보기** 버튼을 누르세요. 승인한 정지 시안 3장을 표시하며, 팔굽혀펴기는 시작 자세·내려간 자세 버튼으로 이미지를 바꿔 비교합니다. 자세 보기 버튼과 타이머 상태 표시는 같은 88×44px 크기를 유지합니다. 가이드를 열어도 운동 타이머는 계속 진행합니다.

원본 이미지는 `assets/postures/`에 포함합니다. 필요한 이미지부터 불러오고 같은 이미지 요청은 공유합니다. 이미지 로딩이 실패하면 측면 그림과 **이미지 다시 불러오기** 버튼을 표시합니다. 자세 설명은 [ACE 플랭크 안내](https://www.acefitness.org/resources/everyone/exercise-library/32/front-plank/)와 [NASM 팔굽혀펴기 안내](https://www.nasm.org/resource-center/exercise-library/push-up)를 참고합니다.

현재 자세 가이드는 이미지 전용으로, Three.js 및 GLB를 불러오지 않습니다. 이전 3D 코드·자산·라이선스는 향후 외부 모델 연결을 위해 보관합니다.

화면 켜짐 유지는 옵션이 켜져 있고 페이지가 보이는 동안 적용되며, **운동 완료 후에도 유지됩니다**. 옵션을 끄거나 다른 페이지·앱으로 이동하면 해제하고, 돌아오면 다시 요청합니다. 이미 해제된 잠금을 `켜짐`으로 표시하지 않으며, `재시도` 상태에서 버튼을 누르면 즉시 다시 요청합니다. 설정은 같은 기기의 같은 브라우저에서 복원되며, 브라우저 데이터를 지우면 삭제됩니다.

iPhone Safari는 iOS 16.4부터 Screen Wake Lock API를 지원합니다. 저전력 모드·배터리 부족·앱 전환·수동 잠금 등 기기 정책으로 화면이 잠기는 경우는 웹사이트에서 막을 수 없습니다. `켜짐`은 브라우저가 반환한 잠금의 유지 상태이며, 운영체제가 화면을 계속 켜둘 것을 보장하지는 않습니다. 관련 문서: [WebKit Safari 16.4](https://webkit.org/blog/13966/webkit-features-in-safari-16-4/#screen-wake-lock-api), [W3C Screen Wake Lock](https://www.w3.org/TR/screen-wake-lock/#managing-wake-locks).

## 배포

이 저장소는 빌드가 필요 없는 정적 사이트입니다. GitHub Pages가 `main` 브랜치의 루트(`/`)를 게시합니다. `.nojekyll`은 정적 파일을 그대로 배포하도록 합니다.

`index.html`과 같은 위치에 CSS 및 JavaScript 파일을 유지하세요. 모든 파일 경로는 상대 경로이므로 `/work/`에서 동작합니다.

JavaScript를 수정할 때는 HTML의 앱 진입 파일과 변경된 모듈 import의 `?v=` 버전도 갱신해 이전 캐시 대신 새 파일을 불러오게 합니다.
